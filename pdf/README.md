# 인쇄용 수업 자료

- `student-worksheet.pdf`: 학생 활동지 2쪽
- `exploration-guide.pdf`: 다섯 장소의 실제 사진 탐험 자료 3쪽
- `teacher-guide.pdf`: 40분 수업 안내와 출처 2쪽
- `full-set.pdf`: 위 자료를 순서대로 합친 7쪽 세트

생성 원본은 `build-pdfs.py`입니다. 장소 설명·사진·날짜·이용 조건은 웹페이지와 같은 `../data/places.json`에서 직접 읽습니다. PDF용 장소 목록을 따로 복제하지 않습니다.
`reportlab`, `Pillow`, `pypdf`가 설치된 Python으로 저장소 루트에서 실행합니다.

```sh
python pdf/build-pdfs.py
```

`node pdf/build.cjs`도 같은 생성기를 실행합니다. 필요한 경우 `PYTHON` 환경 변수로 Python 실행 파일을 지정합니다.

사진은 원본 파일을 직접 삽입하며 전체 화면과 원래 가로세로 비율을 유지합니다. 자르기·필터·덧그리기·재인코딩을 하지 않습니다. 특히 공공누리 제4유형 사진의 변경금지 조건을 지킵니다. 촬영일이 확인되지 않은 사진의 게시일을 촬영일로 바꾸어 쓰지 않습니다.

학습용 그림지도는 실제 좌표의 위치 관계를 단순화한 것으로, 축척이나 실제 이동 경로를 나타내지 않습니다. 오송역과 오송선하마루는 같은 지도 대표점을 사용하고, 선하마루의 공식 안내 위치를 별도로 표기합니다. 원문·이용허락 링크는 PDF에서 클릭할 수 있습니다.
