# 오송 동네 탐험대

2022 개정 교육과정 초등 2학년 통합교과 수업을 위한 오송 마을 탐방 정적 웹사이트입니다. 우리 동네 지도, 장소 카드, 학생용 활동지와 교사용 PDF를 제공합니다.

## 우리 동네 탐방 시작하기

**[🗺️ 우리 동네 지도 열기](https://enffl12230-source.github.io/osong-town-classroom/)** · [학생용 활동지](pdf/student-worksheet.pdf) · [교사용 안내서](pdf/teacher-guide.pdf)

지도나 사진 카드에서 오송역, 오송선하마루, 정중근린공원 물놀이장, 오송생명과학단지 보건지소, 오송읍 행정복지센터를 탐험합니다. 사진을 살펴보고 퀴즈를 풀면 다섯 장소의 도장을 모을 수 있습니다. 탐험 노트는 같은 브라우저 탭에 저장되며 인쇄하거나 PDF로 저장할 수 있습니다.

학생 활동지 2쪽, 실제 사진 학습자료 3쪽, 교사용 안내 2쪽을 각각 또는 [전체 7쪽 PDF](pdf/full-set.pdf)로 내려받을 수 있습니다. 2024~2026년 공개된 실제 사진을 사용하며, 사진마다 출처·날짜 종류·이용 조건을 표시합니다. 사진은 비상업적 교육용으로 이용 조건에 따라 재사용해 주세요.

## 코드는 어떻게 구성되어 있나요?

| 파일 | 역할 |
| --- | --- |
| [index.html](index.html) | 지도, 장소 목록, 장소 상세 창 등 화면의 기본 구조를 정합니다. |
| [style.css](style.css) | 화면의 색상, 글자 크기, 카드 배치를 정합니다. |
| [app.js](app.js) | 장소 자료를 읽어 목록을 그리고, 장소를 선택하면 상세 창을 엽니다. 지도와 방문 표시도 이 파일에서 처리합니다. |
| [data/places.json](data/places.json) | 웹과 PDF가 함께 사용하는 다섯 장소의 설명, 관찰 질문, 퀴즈, 사진 출처를 담습니다. |
| [assets/](assets/) | Leaflet 라이브러리, 글꼴, 실제 장소 사진과 그림지도를 담습니다. |
| [pdf/](pdf/) | 학생 활동지, 사진 학습자료, 교사용 안내서와 PDF 생성 원본을 담습니다. |

장소 정보를 고치려면 `data/places.json`을 확인하세요. `app.js`가 자료를 불러와 지도와 사진 탐험 화면을 표시합니다. 학생 기록은 서버로 전송하지 않습니다. 도장과 노트는 브라우저의 `sessionStorage`에 저장되므로 탭을 닫기 전에 필요한 기록을 PDF로 저장해 주세요.
